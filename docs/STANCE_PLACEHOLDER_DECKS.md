# 站位占位牌组与数值归档

当前默认占位 encounter 口径已并入 [BATTLE.md](BATTLE.md) 的“默认占位 encounter”小节。

保留结论：

- 默认测试 encounter：`enc_stance_probe`。
- 玩家数值：`stance_player_probe`。
- 敌方数值：`stance_enemy_probe`。
- 玩家牌组：`player_stance_probe`。
- 敌方牌组：`enemy_stance_probe`。
- 启用时只改当前 encounter 或新增测试 encounter，不批量覆盖。

后续若调整占位方案，直接更新 [BATTLE.md](BATTLE.md) 和对应 TSV。
