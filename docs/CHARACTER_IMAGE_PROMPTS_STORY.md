# 3. 师父：沉默老兵

## 武器锁定


# 6. 小股倭寇首领

```text

禁止：持刀、持剑、持枪、穿甲上阵、直接战斗姿态。
```

“海商宴”节点核心人物。表面文明、富足、礼数周全，背后是盐利、军械、通倭和地方权势。他不是恶霸脸，而是越温和越危险。

# 8. 失械案押运官

## 武器锁定

```text
主武器：押运军用短枪 / 短矛，长度短于长枪，适合押车护卫。
副武器：腰刀，备用。
核心道具：半损军令牌、押运名册、运输符牌。
禁止：长剑、巨刀、现代枪械、华丽武器。
```

## 角色定位

关键旧案人物，知道军械如何流失。他不是纯反派，而是执行了不敢问的命令。关键词：疲惫、恐惧、麻木、被上头命令压垮。

## 概念设定图提示词

```text
明代失械案押运官，旧案关键 Boss 或事件人物。身穿风尘仆仆的押运军官甲胄，甲上有长途押运留下的尘土、雨痕和破损。主武器必须是押运军用短枪或短矛：木杆较短，铁头实用，适合押车护卫；腰间可挂备用腰刀，但不要画成长剑或巨刀。腰间必须有运输符牌、半损军令牌和旧账袋，手中可拿残破押运名册或封口军令。脸上有刀疤，眼神疲惫、惊惧、麻木，像一个多年执行命令却不敢问真相的人。整体气质不是邪恶，而是被军令和权势压弯的中层军官。明代军务旧案氛围，低饱和土色、旧铜色，全身角色设定图，干净背景。
```

## 头像 / 半身立绘提示词

```text
失械案押运官半身头像，风尘旧甲，脸有刀疤，眼神疲惫惊惧。画面必须出现半损军令牌、残破押运名册或运输符牌；武器只露出押运短枪的枪头或腰刀刀柄，不要出现长剑和现代枪械。暗色明代军务悬疑风，低饱和水墨色。
```

## 关键剧情镜头提示词

```text
山道上停着一辆空押运车，车辙很深，车上什么都没有。失械案押运官站在车旁，手持押运短枪或短矛，腰间挂半损军令牌和旧账袋，另一只手摸向怀中的押运名册。他神情疲惫惊惧，像知道自己会被灭口。暗色明代军务悬疑风，雨痕、泥路、空车、低饱和土色。
```

# 9. 兵变营头

## 武器锁定

```text
主武器：破损长枪 / 营中旧枪，枪杆有裂痕，枪头有锈，代表基层军伍。
副武器：破旧腰刀，可挂腰间。
核心道具：泡烂的欠饷册 / 军饷账本。
禁止：巨斧、巨剑、魔法武器、现代枪械、怪物化武器。
```

## 角色定位

孤城地图 Boss。不是传统反派，而是被拖欠军饷、埋过兄弟、被军令逼到兵变的军头。他应该像主角的一种未来：如果主角被功名和军令压垮，也会变成这样。

## 概念设定图提示词

```text
明代兵变营头，孤城 Boss，悲剧型敌人。身穿破损军甲和脏旧战袍，头缠撕裂暗红布条，胡须粗乱，脸上有疲惫、饥饿和怒火。主武器必须是破损长枪或营中旧枪：木质枪杆有裂痕，铁枪头有锈，枪缨残破，代表基层军伍，不要画成巨斧、巨剑或魔法武器；腰间可挂破旧腰刀作为副武器。另一手可攥着被雨水泡烂的欠饷册或军饷账本。身后是饥饿士兵、旧军旗和孤城烟尘的模糊影子。气质危险、愤怒、但非常有人味；他不是坏人，而是被军令、欠饷和死人逼成的反抗者。暗色明代战场武侠风，低饱和泥土色、暗红点缀，全身 Boss 角色设定图，干净背景。
```

## 头像 / 半身立绘提示词

```text
兵变营头半身头像，破甲，暗红头巾，粗乱胡须，眼神疲惫又燃着怒火。画面必须出现破损长枪的枪杆或锈枪头，以及泡烂的欠饷册；腰间可露出破旧腰刀刀柄。背景为孤城烟尘和旧军旗暗影，明代军伍悲剧人物，暗色水墨风。
```

## 关键剧情镜头提示词

```text
欠饷营门前，军旗挂着但粮袋是空的。兵变营头站在雨泥里，手持破损长枪，枪杆有裂痕，锈枪头和残破枪缨清楚可见，腰间挂破旧腰刀，另一手攥着泡烂的欠饷册。人物饥饿、愤怒、疲惫，但不是怪物。背景有旧营门、冷雨、孤城烟尘和沉默士兵暗影。
```
