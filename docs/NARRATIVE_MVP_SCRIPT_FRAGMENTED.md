# 《沧海嘀鸣》MVP 碎片化叙事脚本

> 目标：根据序章节奏，重写完整 MVP 节点文本。
>
> 风格关键词：极度压缩、碎片化、隐晦叙事、动作先于解释、信息缺页、潮声反复、火器旧案不直说。
>
> 使用原则：不解释世界观，不讲完整案情；只给玩家“看到的片段”和“被迫做出的选择”。

---

## 0. 总体叙事规则

```text
1. 单句尽量短。
2. 不说“真相”，只说“痕迹”。
3. 不说“阴谋”，只说“缺页、暗箭、火器、名册”。
4. 不写长对白，所有人都像在藏半句话。
5. 每个节点只给一个核心意象。
6. 每次战斗前不解释敌人是谁，只让玩家知道“他挡路”。
7. 每次战斗后不总结，只掉下一枚碎片。
```

# 二、第一幕：潮下有铁

## 节点 1：军令巡海

### 表演意象

```text
军门。
湿案牍。
朱批没干。
```

### 节点正文

```text
军令压在案上。

出海。
巡岸。
剿寇。

最后一行被墨盖住。
```

### 选择

```text
问旧案
```

结果语气：

```text
上官看了你一眼。
像看见故人。
```

```text
领命出发
```

结果语气：

```text
印落下。
潮也落下。
```

```text

你看见他靴上的官泥。

```


# 三、MVP 结局文案

## 结局标题

```text
潮声还在
```

## 结局正文

```text
军功写进册里。

清望写在别人嘴里。

线索藏在袖中。

案卷少了一页。

潮声没有少。
```

```text
你赢了几场。
升了几分。
也只多知道一点：

倭寇从海上来。
箭从岸上来。
```
