# 《大明之沧海嘀鸣》MVP 场景美术提示词

> 用途：用于序章插画、地图节点背景、事件 CG、Boss 场景、结局图。  
> 来源：`docs/MVP_NARRATIVE_SCRIPT.md`。  
> 风格基准：明代沿海军务、暗色武侠、碎片化隐晦叙事、旧案、军令、倭患背面、功名变形。  
> 注意：本文件只服务剧情场景美术，不包含像素风、Sprite、透明背景、单帧动作等要求。


# 1. 序章：黑屏潮声 / 火从海边来

## 用途

序章开场视觉基调图。用于“十年前，海退得很远”的黑屏后第一张暗示画面。

## 画面要点

```text
时间：十年前夜晚
地点：明代沿海渔村外
元素：退潮泥滩、远处村火、潮声、黑暗海面、低云
人物：可无人，或只有极远处小小人影
情绪：压抑、悬疑、灾难刚开始
```

## 提示词

```text
明代沿海渔村的夜晚，退潮后的泥滩露出大片湿黑沙地，远处村落开始燃烧，火光很低，被海风吹斜，黑暗海面像一块沉默的铁，低云压住天际。画面几乎没有人物，只有远处模糊的逃散人影和倒下的旧军旗影子。气氛压抑、克制、隐晦，像灾难刚开始而真相尚未出现。暗色武侠历史叙事风，低饱和水墨色，电影感宽画幅构图，不表现血腥细节。
```

# 2. 序章：父亲与敌人黑屏对白的画面

## 用途

配合对白：

```text
父亲：“孩子不知道。”
敌人：“死人也不知道。”
```

## 画面要点

```text
地点：燃烧村屋门内或门外
元素：半开的木门、刀影、父亲剪影、火光、孩子藏身处
人物：父亲只做剪影，敌人只露刀影，不正面解释
情绪：压迫、无力、不能直视
```

## 提示词

```text
明代沿海渔村燃烧的木屋门口，半开的木门挡住大部分画面，门缝中只有父亲的黑色剪影和敌人举刀的影子。火光从门后溢出，地上有破碎祖牌、粗布衣角、散落米粒。孩子没有正面出现，只在画面边缘留下一只紧攥布片的小手。画面表现“孩子不知道”和“死人也不知道”的压迫感，不展示血腥，只用门、刀影、火光和沉默制造恐惧。暗色水墨历史风，低饱和火光，电影感构图。
```

