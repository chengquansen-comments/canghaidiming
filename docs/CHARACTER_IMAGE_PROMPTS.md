# 《大明之沧海嘀鸣》主要人物形象设计提示词

> 用途：用于主要人物概念设定图、头像立绘、战斗 Sprite、宣传图的 AI 美术生成。  
> 风格基准：明代沿海军务、碎片化武官肉鸽叙事、暗色武侠、旧案、军令、倭患背面、功名变形。  
> 当前优先角色：主角、童年主角、师父、敌方枪手、敌方刀客、小股倭寇首领、海商豪强、失械案押运官、兵变营头。

## 0. 通用风格提示词

所有人物提示词建议统一追加以下风格段，保持项目美术一致性：

```text
明代沿海军务题材，暗色武侠历史幻想风，写实但带游戏概念设计质感，低饱和水墨色调，深青灰、旧铜色、暗红点缀，海风、泥水、烟尘、旧军旗、破损甲胄、压抑氛围，人物表情克制，有旧案和命运感，全身角色设定图，轮廓清晰，服饰结构可读，干净背景，适合游戏角色设计，不要现代元素，不要赛博朋克，不要欧式骑士甲，不要夸张玄幻盔甲，不要可爱 Q 版。
```

```text
现代服装，赛博朋克，日式校园动漫风，欧式骑士盔甲，精灵，魔法袍，巨大荧光武器，塑料质感盔甲，过亮卡通色，Q版，科幻枪械，多人物，重复身体，裁脚，手指畸形，脸部不一致，武器前后不一致，过度华丽装饰，纯玄幻盔甲，背景过于复杂，现代建筑。
```

# 1. 主角：年轻武官

## 角色定位

屠村旧案的幸存者，被沉默老兵养大，踏入明代武官之路。表面是新晋武官，内里压着复仇、忠义、功名、求生之间的撕扯。形象不能太爽朗，也不能太邪气，要有年轻人的锋利和被旧案压住的沉默。

## 概念设定图提示词

```text
一名年轻的明代沿海武官，旧案屠村幸存者，暗色武侠历史游戏角色设定。身穿深青灰色布甲与皮甲结合的实战甲胄，甲片有海风和泥水侵蚀痕迹，腰间系旧布护符，背负短枪或长枪，腰侧挂实用短刀。脸庞年轻但神情压抑，眼神克制而有怒意，像一个正在复仇、军令、功名、救民之间做选择的人。整体气质冷峻、坚忍、未完全成熟，但已经经历过火与血。明代沿海军务氛围，低饱和水墨色调，深青灰、旧铜、暗红点缀，全身角色设定图，干净背景，轮廓清晰，适合游戏主角立绘。
```

## 头像 / 半身立绘提示词

```text
年轻明代武官半身头像，深青灰战袍与旧皮甲，脸上有轻微烟尘和旧伤，眼神沉默克制，眉间有压住的怒意，背景为模糊海风与旧军旗暗影，暗色武侠历史游戏立绘，低饱和水墨色，细节清晰，适合剧情对话头像。
```

## Sprite 方向提示词


# 2. 主角童年：火中余生的孩子

## 角色定位

序章“刀下余声”中的童年主角。不是可爱儿童，而是屠村火光中的幸存者。这个形象主要用于序章、梦境、旧案碎片、回忆立绘。核心情绪是恐惧、茫然、被迫记住。

## 概念设定图提示词

```text
一个明代沿海渔村出身的男孩，主角童年形象，屠村火灾后的幸存者。穿着被烟熏黑的粗布短衣，衣角烧破，脸上有灰尘和泪痕，手里紧攥一小块母亲留下的布片或半块祖牌。身形瘦小，赤脚或穿破草鞋，站在退潮后的泥沙与灰烬边缘，远处只有模糊火光和倒塌屋影。表情不是哭喊，而是被吓到失声，眼神空、紧、记住了什么。暗色水墨历史风，克制悲伤，明代沿海村落氛围，全身角色设定图，干净背景或极简火光背景，适合序章回忆立绘。
```

## 序章场景提示词

```text
明代沿海渔村屠村后的夜晚，一个小男孩躲在米缸旁或破船底，衣服被烟熏黑，手里攥着布片，火光照亮半张脸，远处是燃烧的村屋和倒下的军旗碎影。画面压抑克制，不表现血腥细节，重点表现恐惧、失声、潮声和命运开始。暗色武侠历史叙事风，低饱和水墨色，电影感构图。
```

## Sprite / 事件图标提示词

```text
明代沿海渔村男孩像素角色，童年主角，粗布短衣，烟灰脸，手握小布片，瘦小沉默，512x512 单帧，透明背景，暗色像素风，轮廓清晰，不要可爱 Q 版，不要夸张表情。
```

# 3. 师父：沉默老兵

## 角色定位

救下主角的老兵，不是仙风道骨的师父，而是背着旧案和亏欠的战场幸存者。他的关键词是沉默、旧伤、迟到、传承、逃避。形象要像“破刀仍利”，旧、疲、危险。

## 概念设定图提示词

```text
一名沉默的明代老兵师父，暗色武侠历史游戏角色设定。身穿褪色旧军甲，外罩多次缝补的深色旧袍，肩甲破损，袖口磨白，腰间挂一把早已不该上阵的旧刀，手背有长年握兵器留下的硬茧和伤疤。头发灰白，胡茬杂乱，眼神疲惫且回避，像一个曾经迟到过一次、从此背着亏欠活下来的人。站姿微驼但危险，像旧鞘里的刀。低饱和水墨色，海风、营火、夜半磨刀氛围，全身角色设定图，干净背景，明代沿海军务感。
```

## 头像 / 半身立绘提示词

```text
沉默明代老兵半身头像，灰白胡茬，旧伤横过手背，深色破旧军袍，眼神疲惫、回避、压着秘密。背景为夜晚营地微弱火光与磨刀影子，暗色水墨武侠风，克制、沉重、少言。
```

```text
敌方明代枪手，训练有素的敌对军伍武人，暗色武侠战斗角色设定。身穿黑蓝色旧布甲和皮甲，甲片边缘磨损，腰间有暗红布条，手持实用长枪，枪缨褪色，站姿稳、冷、压迫感强。脸部半遮阴影，眼神冷漠，不像盗匪，而像被军令和利益驱使的职业战士。明代沿海战场氛围，低饱和暗色调，轮廓清晰，全身角色设定图，干净背景。
```


## 头像 / 半身立绘提示词

```text
明代海商豪强半身头像，深色丝绸长袍，玉扳指，温和微笑，眼神冷静危险，身后有模糊海图和宴席烛光，暗示通倭、盐利、军械交易，低饱和暗金水墨风，适合事件对话立绘。
```
