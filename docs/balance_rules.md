# 旧卡牌预算规则归档

当前战斗数值入口已整合到 [BATTLE.md](BATTLE.md)。本文原本记录早期基础牌预算公式，现只保留历史结论。

## 历史公式

```text
效果预算 = 增己势 * 2 + 削敌势 * 2 + 伤害 + 格挡
目标预算 = 耗势 * 4
```

这个公式仍可作为低阶基础牌自检参考，但不再是唯一平衡来源。当前调数值时优先使用已有 TSV、卡牌定义、职业 profile、正式剧情奖励和调参工具；除非用户明确提出或批准，不新增数值线、成长线、资源线或隐藏倍率。

后续若要恢复或替换预算公式，先更新 [BATTLE.md](BATTLE.md)，再同步卡牌定义、sampler 和调参工具。
