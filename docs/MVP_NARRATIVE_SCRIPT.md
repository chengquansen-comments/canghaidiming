# 《大明之沧海嘀鸣》MVP 叙事脚本

> 版本：v0.1  
> 目标：只做一个高完成度叙事原型，不做完整明代武官人生。  
> 结构：一张肉鸽地图 + 三个叙事变量 + 一条旧案闭环。  
> 叙事原则：少说，硬说，藏着说。每个节点只给玩家一小块碎片。

---

## 0. MVP 设计边界

### 0.1 本版本只做三层内容

```text
第一层：一张肉鸽地图
节点类型：普通战斗 / 精英战斗 / 事件 / 营地 / 旧物 / Boss

第二层：三条叙事变量
军功 / 清望 / 旧案线索

第三层：一个完整旧案闭环
倭寇袭村
→ 明制火器
→ 失踪军械
→ 师父旧部
→ 军门压案
→ 玩家选择上报、掩盖、私查或借势
```

### 0.2 本版本暂不做

```text
不做完整人生线；
不做官阶系统；
不做封爵大结局；
不做 8 变量全量系统；
不做多地图章节；
不做长篇对白；
不做传统任务说明式剧情。
```

## 2. 叙事变量

### 2.1 变量一：军功

```text
含义：战场功绩，被军门看见的胜利。
倾向：杀敌、速胜、服从军令、交出证据。
影响：影响军门评价与最终小结局。
```

### 2.2 变量二：清望

```text
含义：百姓、士卒、言官眼中的道义评价。
倾向：救人、据实、拒宴、保存证人。
影响：影响百姓评价与结局文本。
```

### 2.3 变量三：旧案线索

```text
含义：十年前屠村与失踪军械案的真相碎片。
倾向：私查、留证、追问、保护证人、调查军械。
影响：决定是否解锁旧案结尾抉择。
```

### 2.4 初始值

```text
军功：0
清望：0
旧案线索：0
```

### 2.5 结局判断优先级

```text
旧案线索 >= 4：进入旧案抉择结局
军功 >= 4 且旧案线索 < 4：进入军功结局
清望 >= 4 且旧案线索 < 4：进入清望结局
三者均低：进入沉默结局
```

## 12. MVP 验收标准

```text
[ ] 序章 5 分钟内完成：黑屏潮声 → 父母遇害 → 童年战斗 0 伤害 → 师父救场 → 暗箭灭口 → 十年后出山
[ ] 地图只包含 6 类节点：普通战斗 / 精英战斗 / 事件 / 营地 / 旧物 / Boss
[ ] 全局只使用 3 个叙事变量：军功 / 清望 / 旧案线索
[ ] 玩家能在一局内理解：倭寇袭村、明制火器、失踪军械、师父旧部、军门压案之间有关联
[ ] Boss 后必须出现四选一：上报 / 掩盖 / 私查 / 借势
[ ] 每个节点对白不超过 3 句，旁白短硬，不解释过度
[ ] 每个选择都有收益，也有代价
[ ] 至少 3 个不同小结局可触发
```

## 13. 一句话总结

```text
这版 MVP 不是讲完主角一生，而是让玩家在一次“初出山”的行军中明白：
十年前那场火，不只从海上来；
你第一次立功时，也第一次学会了沉默的价钱。
```
