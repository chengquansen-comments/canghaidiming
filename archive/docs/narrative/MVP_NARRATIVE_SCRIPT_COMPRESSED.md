# 《大明之沧海嘀鸣》MVP 压缩叙事脚本

> 版本：v0.2 压缩版  
> 目标：把 MVP 叙事压到“短镜头 + 短对白 + 短选择”的幅度。  
> 原则：不解释，不铺陈，不写长对白；只给玩家足够的伤口、疑点和选择压力。  
> 优先级：本文件作为开局序章和单局叙事实现的优先参考。

---

## 0. 压缩叙事总原则

```text
每段叙事最多只回答一个问题；
每句对白尽量不超过 10 个字；
每个节点最多 1 句旁白 + 2 句对白 + 3 个选择；
旧案信息只给碎片，不给解释；
玩家通过重复出现的物件理解真相：火器、军报、押运牌、旧枪缨、暗箭。
```

### 0.1 本版叙事幅度

```text
黑屏 / 声音 / 一句对白 / 一个动作 / 一个物件 / 一个选择。
```

### 0.2 禁止写法

```text
禁止长篇背景介绍；
禁止角色解释旧案；
禁止 NPC 直接说完整真相；
禁止把明代制度讲成说明书；
禁止每个节点都讲满三段剧情。
```

# 1. 开局序章：刀下余声｜极短镜头链

> 目标时长：2 - 3 分钟。  
> 功能：建立主角创伤、师父救命、旧案悬念。  
> 形式：黑屏 + 极短对白 + 一场教学失败 + 一场师父接管战斗。

# 11. 最终四选一

## 11.1 上报

```text
选择：据实上报。
条件：旧案线索 >= 3
结果：清望 +2，军功 -1
结语：船离港，雾也起了。
```

## 11.2 掩盖

```text
选择：只报剿寇。
条件：无
结果：军功 +2
结语：捷报很顺，不像真的。
```

## 11.3 私查

```text
选择：藏下一份证据。
条件：旧案线索 >= 2
结果：军功 +1，旧案线索 +2
结语：你交了一份真的，也留了一份更真的。
```

## 11.4 借势

```text
选择：拿证据换船粮。
条件：经过海商宴
结果：军功 +1，旧案线索 +1，清望 -1
结语：证据没沉海，只是换了主人。
```

# 13. 压缩版验收标准

```text
[ ] 开局 3 分钟内完成
[ ] 黑屏潮声后 3 句内进入冲突
[ ] 幼年主角只打一张 0 伤害木刀牌
[ ] 师父只用 3 张强力牌
[ ] 敌人只说“军……”即被灭口
[ ] 十年后只有一句“该出山了”
[ ] 每个地图节点最多 1 句旁白 + 2 句对白
[ ] 旧案信息只通过物件和短句出现
[ ] Boss 后必须进入军门压案
[ ] 最终四选一保持：上报 / 掩盖 / 私查 / 借势
```
