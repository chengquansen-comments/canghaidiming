## Scope Model

This audit separates file-size risk into two primary scopes:

- **Code risk**: `.gd`, `.py`, and shader files. These should follow the 25KB code-organization rule strictly.
- **Data / document risk**: TSV, JSON, Markdown, scene, resource, and config files. Large files here are not automatically code refactor blockers, but may need data-source or documentation cleanup.
